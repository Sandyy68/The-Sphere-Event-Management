# Sphere Event Management

**Sphere Event Management** is a **web-based platform** for managing **shows, events, and ticket bookings** at **The Sphere**. Built with **PHP, MySQL, HTML, CSS, and JavaScript**, it includes a **CRUD system** to **add, edit, delete shows**, **view events**, and **manage details**. This project highlights **full-stack development**, **database management**, and **responsive UI design**.

## Features
- **Add, edit, delete, and view shows**
- **Check ticket availability**
- **Seamless event management**
- **Responsive UI design**

## Technologies Used
- **PHP**
- **MySQL**
- **HTML, CSS, JavaScript**

## Installation
1. Copy the project to `htdocs` in **XAMPP**.
2. Start **Apache** and **MySQL** in XAMPP.
3. Import `FinalProject.sql` into **phpMyAdmin**.
4. Open in browser: `http://localhost/FinalProject`.
